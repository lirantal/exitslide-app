# Compound Engineering for Codex

These project skills come from [Compound Engineering 3.38.2](https://github.com/EveryInc/compound-engineering-plugin/tree/8f7614639e7f3792a6f9337d8742a80a232bd596).
This directory contains the upstream `skills/` tree and its MIT license.

Codex discovers these files under the repository's `.agents/skills/` directory.
Open a Codex session in this checkout and invoke a skill by name, for example
`$ce-help` or `$ce-plan`. Run `$ce-setup` to check optional tools and configure
Compound Engineering for this project.

To update the skills, replace this snapshot with the upstream `skills/` tree
and `LICENSE` from the chosen revision, then update the source link above.
